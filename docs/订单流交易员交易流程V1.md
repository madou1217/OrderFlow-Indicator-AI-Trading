位置 → 状态 → 驱动 → 触发 → 执行

4H–1D 的高质量交易，不是“把所有指标看一遍”，而是先回答五个问题：
价格现在在哪儿？市场现在是什么状态？是谁在推动？关键位上有没有确认？这笔单的失效点和目标点清不清楚？
你的文档里，结构层有 PVS / TPO / AVWAP / RVWAP / EMA，微结构层有 footprint / orderbook_depth / CVD / absorption / initiation / exhaustion，风险层有 liquidation / funding / VPIN，新增的 OI 和 long-short ratios 则补上了“仓位结构”这一层，已经很接近完整决策栈了。

先把 26 个指标降维

我会这样分层：

位置层：1 price_volume_structure、4 liquidation_density、18 AVWAP、20 TPO market profile、21 RVWAP sigma bands、23 EMA trend regime，如果你的 24 是 FVG/缺口类，也归这里。它们负责回答“这里值不值得做”。PVS 给你 POC/VAH/VAL/HVN/LVN，TPO 给你 IB / Single Prints / session POC，RVWAP 给你 15m/4h/1d 的偏离带，EMA 则给 4h/1d EMA100/200 的 regime。19 kline_history只是数据载体，不该进入打分；8–11 只是 6/7 的方向衍生标签，不单独加权。

状态层：16 funding、17 VPIN、25 open_interest、26 long_short_ratios。这层不负责入场，只负责回答“这波更像加仓、减仓、挤仓，还是拥挤到要反身”。文档里 OI 已经明确分成 leveraged_long_build / fresh_short_build / long_unwind / short_cover，long_short_ratios 也给了 crowded_long / crowded_short / unwind / balanced。而且 i25/i26 的输入是确认后的 5m 规范桶，并且允许边界后晚到，所以它们天然属于状态层，不适合做秒级或 1m 触发。

驱动层：14 CVD pack、3 divergence、15 whale trades。这层负责回答“是谁在推，现货还是合约，是真推动还是假推动”。你的 divergence 文档已经非常对：它不是直接拿原始 CVD 水平做背离，而是先做去趋势 + robust z-score + 显著性 + spot/futures 归因，并要求 event_available_ts，这正是 4H–1D 里该用的背离方式。也就是说，我不会拿“原始 CVD 看起来背离”就下结论，我只看去趋势后的有效背离，以及是不是 spot_led。

触发层：2 footprint、5 orderbook_depth、6 absorption、7 initiation、12 buying exhaustion、13 selling exhaustion、22 high_volume_pulse。这层负责回答“关键位上到底发生了什么”。footprint 给的是 stacked imbalances / unfinished auction；orderbook_depth 给的是 OBI / OFI / microprice / spot confirm / fake_order_risk；absorption/initiation/exhaustion 都带了确认逻辑和现货确认字段，所以这是我真正等信号的地方。

我的真实工作流
1）先做 1D / 4H 地图，不找进场

先用位置层把图画出来：

1D / 4H 的 POC, VAH, VAL, HVN, LVN
1D session 的 TPO POC / IB / Single Prints
关键锚点的 AVWAP
4H / 1D RVWAP ±1σ/±2σ
主要爆仓密度峰值区
4H / 1D EMA100/200 regime

这一层只做一件事：把价格分成三类——在价值区内、在价值区边缘、已经离开价值区且过度延伸。如果价格在区间中间，我通常直接不做。

2）再看 4H 状态，只选一种剧本

我只允许自己在 4H 上选三种剧本：

延续：价格与 OI 同向扩张，ratio 没到极端拥挤，funding/VPIN 没明显反噬，趋势结构顺着 EMA100/200。
拥挤反转：价格已经到 1D/4H 极限位置，ratio 拥挤，funding 偏一边，OI 继续堆但价格推进效率下降。
回归价值：价格离开 value 但没形成真正接受，准备回 POC/HVN/AVWAP/RVWAP。

这里最关键的不是”多空”，而是当前 move 的仓位属性。比如 price↑ + OI↑ 更像真加仓，price↑ + OI↓ 更像 short cover；这两种我对待完全不一样。

剧本切换规则：剧本不是选了就锁死。当触发层出现与当前剧本矛盾的高质量信号时，必须强制重新评估剧本。具体条件：
- 价格到达 1D/4H 极限位置（RVWAP ±2σ、爆仓峰值区、thesis floor/ceiling），且
- 触发层已确认反向信号（exhaustion + divergence 同时出现，或 absorption 确认），且
- 驱动层出现变化（推进效率坍塌、spot/futures 关系翻转）

满足以上三条时，旧剧本失效，必须重选。这不是”15m 改剧本”，而是”新证据推翻旧剧本”。
实战案例：如果当前剧本是”延续（空方）”，但价格到了 4H sigma2 floor 并出现 selling exhaustion + bullish divergence + bid wall hold，那”延续”剧本已经失效，必须切换到”拥挤反转”重新评估。

2.5）每个剧本都必须落成一个 scenario/path object

只给自己贴一个标签不够。真正做单前，我必须把当前剧本写成一个明确的路径对象，而不是只写“延续 / 反转 / 回归价值”。

一个可执行的 scenario/path object 至少要回答六件事：

- thesis：当前主剧本是什么，为什么是它，不是另一个。
- activation_level：哪一个价格或价格带被确认后，这个剧本才算正式激活。
- first_path_target：一旦激活，价格第一段最可能先去哪里。
- next_path_target：如果第一段走出来，下一层路径再去哪里。
- failure_level：哪个价格或价格带失守，这个剧本就失效。
- failure_switch：如果失效，下一时间优先切换到哪个替代剧本。

也就是说，我不是只问“现在更像延续还是反转”，而是要明确：

- 只要 X 被确认，路径先去 Y
- 如果 Y 到达后还维持当前驱动，下一层去 Z
- 如果 X 失败，剧本切换到 W

这个对象必须是价格化的，而不是抽象描述。activation、target、failure 都必须绑定到 1D/4H 的具体结构位。

一个合格的示例应该像这样：

- thesis：4H 空头延续
- activation_level：2055-2050 支撑失守并在其下接受
- first_path_target：2042 一带 recent swing low
- next_path_target：2033 一带 panic low / liquidation shelf
- failure_level：价格重新收回 2063-2068 并得到 spot-led 接受
- failure_switch：从空头延续切换到 failed breakdown -> 回归价值 / 拥挤反转

或者：

- thesis：4H reclaim 反转
- activation_level：2033 flush low 被买回，随后重新站上 2046-2051 reclaim band
- first_path_target：2064-2068
- next_path_target：2072-2080
- failure_level：重新跌回 2033 下方并在其下接受
- failure_switch：从 reclaim 反转切回 bearish continuation

这一步的作用，是把“市场状态分析”真正转换成“可交易路径”。没有 scenario/path object，后面的触发和执行就会沦为看到信号就反应；有了它，触发层只是在确认哪条已经预先定义好的路径开始兑现。

3）再做 4H 驱动归因：现货在不在场

这一层我只看三件事：

CVD / divergence 是不是有效，不是原始曲线看着像
现货是不是在同方向确认
这波更像 spot_led、futures_led 还是 mixed

如果价格在涨，但只有合约侧在冲，现货 spot flow confirm 不在，或者 spot_lead_score 很弱，我会把这波当成脆弱延续。
反过来，如果现货主导、合约没跟上，那更容易出现后续追价和加速。

4）15m 只等 setup，不再改剧本

到了 15m，我只等三类 setup。

A. 延续单
前提是价格先到我在 1D/4H 画好的边缘位或再接受位，然后出现：

initiation 事件
footprint 的 stacked imbalance
OBI / OFI / microprice 同向
spot_confirm = true
fake_order_risk 低
OI 状态仍支持，而不是已经进入拥挤 unwind

这种单我本质上做的是“接受后的第二段”。

B. 反转单
我只在这些地方找反转：

1D/4H LVN/HVN
RVWAP ±2σ
爆仓峰值区
AVWAPGap 极端
IB extension 或 Single Print 末端

然后必须出现：

absorption 或 buying/selling exhaustion
有效 divergence
现货没有继续推同方向，或者出现 spot continuation risk = false
footprint 里出现失衡失败 / 拍卖未完成 / 主动单推进不了价格

这种单不是“猜顶猜底”，而是做拥挤失效。

C. 回归价值单
本质是 failed auction：

先突破 VAH/VAL/IB/FVG 一类外沿
但没有得到 OI 扩张、spot 确认、持续 OFI 支持
收回 value 内

这类单的目标通常不是趋势末端，而是回 POC / HVN / AVWAP / RVWAP 中枢。

5）真正下单时，只让 1m / 100ms 负责“怎么进”，不负责“该不该进”

1m/100ms 我只拿来做三件事：

看 footprint 最后一脚是不是有 stacked imbalance / UA / delta trap
看 OFI、microprice、OBI 有没有临门一脚同向
用 intrabar POC 找更好的成交与更紧的失效点

也就是说，1m 是 execution frame，不是 decision frame。
文档里 high_volume_pulse 的 intrabar_poc 非常适合做这一层，但不该拿它单独决定方向。

6）出场和管理

我不会“固定 1:2 就走”。

第一目标通常放在最近的：

POC / HVN / LVN
AVWAP
RVWAP ±1σ / ±2σ
TPO single print
爆仓密度峰值区

而不是随便拍一个 RR。
持仓中最重要的是看：驱动有没有变。如果这笔单原本是 spot_led + initiation，后来变成了 OI 缩、spot 不跟、fake order risk 上升，那就算价格没到硬止损，我也会减仓或走人。

我实际会用的”硬过滤器”

一笔 4H–1D 的单，分两层过滤：

Hard gate（必须全部满足）：
- 位置够好：不是区间中间，而是在 value 边缘、锚点、σ 带、IB、single print、liq zone 一类位置。
- 触发已确认：不是裸猜，要有 initiation / absorption / exhaustion / divergence。

Soft gate（满足 3/4 即可）：
- 状态清楚：OI/ratio/funding/VPIN 告诉我这是 build、unwind 还是 crowding。
- 驱动清楚：spot-led、futures-led、还是 mixed。
- 盘口是真实的：OBI/OFI 与成交同向，spot confirm 在，fake order risk 不高。
- 失效点明确：我知道错在哪，不是随手放个止损。

如果只能记一句，就是：

先做位置，再看仓位状态，再判定谁在推动，最后等事件触发。
